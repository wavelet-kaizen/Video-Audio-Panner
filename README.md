# Video Audio Panner

**Holodexなどの複窓ツール専用** - 複数の動画を同時再生する時に、音声を左右に振り分けて聞き分けやすくするChrome / Edge拡張機能です。Holodexのmultiviewでは表示位置に合わせて自動調整するため、ツールバーがない全画面のPWAでも利用できます。

## これは何？

Holodexなど、**1ページ内に複数の動画を同時再生できるツール**で使うための拡張機能です。

### 解決する問題

Holodexで4つの配信を同時に見ているとき、全ての音声が中央から聞こえて混ざってしまい、誰が何を喋っているのか分からなくなったことはありませんか？

この拡張機能を使うと：
- **左上の動画 → 左のスピーカーから**
- **右上の動画 → 右のスピーカーから**
- **左下の動画 → 少し左寄りから**
- **右下の動画 → 少し右寄りから**

というように、それぞれの音声を別々の方向から聞こえるようにして、格段に聞き分けやすくします。

### 想定している使い方

- **Holodexで複数のVTuber配信を同時視聴**: 推しの配信を2〜4画面で開いて、それぞれの実況を聞き分ける

### 対応しているツール

1ページ内に複数の`<video>`要素を配置するタイプのツールなら、基本的に使えます：
- ✅ Holodex
- ✅ その他の複窓ツール
- ❌ 普通のYouTube（1動画しかないので意味がない）
- ❌ 通常のニコニコ動画（同上）

### 主な特徴

- Holodexのmultiviewでは、動画の追加・削除・配置変更に合わせて自動調整
- iframe内の動画も含めて画面上の位置を判定（4動画まで）
- その他のサイトでは、ツールバーのボタンをクリックして適用
- 振り分け後の確認メッセージやポップアップは表示しない

## インストール方法

### 方法1：開発者モードで使う（推奨）

この拡張機能はChromeウェブストアには公開されていないので、自分でインストールする必要があります。

Edge Canaryでは、以下の `chrome://extensions/` を `edge://extensions/` に読み替え、PWAを使うプロファイルに拡張機能を読み込んでください。

1. **拡張機能の管理画面を開く**
   - Chromeのアドレスバーに `chrome://extensions/` と入力してEnterキーを押す
   - または、右上の三点メニュー → 「拡張機能」→ 「拡張機能を管理」をクリック

2. **デベロッパーモードをONにする**
   - 画面右上にある「デベロッパーモード」のスイッチをクリックしてONにする

3. **拡張機能を読み込む**
   - 「パッケージ化されていない拡張機能を読み込む」というボタンが表示されるのでクリック
   - ファイル選択ダイアログが開くので、このプロジェクトのフォルダ（`manifest.json`があるフォルダ）を選択
   - 「フォルダーの選択」をクリック

4. **完了**
   - Chromeツールバーに「Video Audio Panner」のアイコンが表示されれば成功です

### 方法2：パッケージファイル（.crx）から使う

もし `.crx` ファイルが用意されている場合：

1. Chromeのアドレスバーに `chrome://extensions/` と入力
2. `.crx` ファイルを画面にドラッグ&ドロップ
3. 「拡張機能を追加」をクリック

### CRXの作成・更新

**リポジトリ直下の `pack-crx.cmd` をダブルクリックしてください。** Node.jsや追加パッケージは不要です。実行結果と保存先を表示したまま待機するので、確認後にキーを押して閉じられます。

この処理では、既存の `env/Video Audio Panner.pem` を使い、Edge Canary、通常版Edgeの順でブラウザーを自動検出します。最新の3ファイルだけを一時フォルダーにコピーし、パック・内容の検証まで自動で行います。秘密キーやテスト用データはCRXに含めません。

出力先は `crx/Video Audio Panner-<manifest.jsonのversion>.crx` です。同じバージョンのCRXは、作成と検証が成功した場合に更新します。失敗時は既存のCRXを維持し、エラーと作業ログの場所を表示します。キーが見つからない場合は、新しいキーを生成せずに停止します。

ターミナルから実行する場合：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\pack-extension.ps1
```

秘密キーやブラウザーの場所を指定する場合は、`-KeyPath` / `-BrowserPath` を追加できます。ブラウザーは環境変数 `EDGE_PATH` でも指定できます。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\pack-extension.ps1 -KeyPath "D:\keys\Video Audio Panner.pem" -BrowserPath "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"
```

ブラウザーの画面から手動でパックする場合は、以下の手順を使います。リポジトリ全体をパックすると、`env/` 内の秘密キーやブラウザーのテストデータも対象になります。`.gitignore` はパック対象の除外設定にはなりません。

1. `crx/Video Audio Panner-1.1/` に、最新の `manifest.json`・`background.js`・`content.js` だけをコピーする（再パック時もコピーし直す）
2. `edge://extensions/` の「拡張機能のパック」で、以下を指定する
   - **拡張ルート ディレクトリ**：`<リポジトリ>/crx/Video Audio Panner-1.1`
   - **秘密キー ファイル**：`<リポジトリ>/env/Video Audio Panner.pem`
3. パックすると `crx/Video Audio Panner-1.1.crx` が作成される

秘密キーはパックするフォルダーの外側に置き、更新時も同じキーを指定してください。キーを専用フォルダー内にコピーする必要はありません。バージョンを上げた場合は、フォルダー名も対応するバージョンに読み替えてください。

## 使い方

### Holodex / Edge CanaryのPWA

1. 拡張機能を読み込んだ後、Holodexのページ（PWAを含む）を再読み込みする
2. `https://holodex.net/multiview` を開いて動画を再生する
3. 動画を追加・削除したり、配置やウィンドウサイズを変更すると、音声の振り分けが自動で更新される

ツールバーの操作は不要です。自動監視はmultiviewとその配下のURLでのみ有効になり、別のHolodexページへ移動すると監視を停止してパンを中央に戻します。短時間の変更はまとめて処理するため、画面の変更から反映まで少し間があります。


ブラウザーの[自動再生制限](https://developer.chrome.com/blog/autoplay#web_audio)によって音声処理の開始が保留される場合は、対象の動画内をクリックするか再生操作を行ってください。処理を開始できるまでは元の音声を維持します。

### その他のサイト

1. 複窓ツールで動画を開いて再生する
2. 拡張機能の **Video Audio Panner** ボタンをクリックする

動画を増減した場合は、もう一度ボタンをクリックしてください。繰り返し実行しても同じ動画の音声ノードを作り直しません。

イヤホンやヘッドホンを使うと、左右の違いがよりはっきり分かります。

## 音声の振り分けパターン

### Holodex multiview：表示位置を優先

動画の番号や追加順ではなく、iframeを含めた実際の表示位置で判定します。非表示の動画・iframeは集計から除外します。

- **1動画**：中央
- **2動画**：画面の左から右へ、左80%・右80%（縦並びでは上から下の順）
- **3〜4動画**：左列は左、右列は右。同じ列の上側は80%、下側は65%。レイアウト中央にある動画は中央
- **5動画以上**：従来どおり左100%・右100%・中央を繰り返す

4動画を以下のように配置した場合、追加順が異なっていても左右を維持します。

```text
左上：左80%    右上：右80%
左下：左65%    右下：右65%
```

3動画で左列に2つ・右列に1つある場合、左下の動画は左65%になります。3動画を横一列に配置した場合は左80%・中央・右80%になります。

### その他のサイト：動画数によるパターン

フレームの並び順と各フレーム内の動画順で、以下のパターンを適用します。Holodexで座標を取得できない場合も、このパターンを使用します。

### 動画が1個の場合
- **真ん中**から聞こえる（普通の状態と同じ）

### 動画が2個の場合
- 1つ目：**左寄り**（左80%）から聞こえる
- 2つ目：**右寄り**（右80%）から聞こえる

### 動画が3個の場合
- 1つ目：**左寄り**（左80%）から聞こえる
- 2つ目：**真ん中**から聞こえる
- 3つ目：**右寄り**（右80%）から聞こえる

### 動画が4個の場合
- 1つ目：**左寄り**（左80%）から聞こえる
- 2つ目：**少し左寄り**（左65%）から聞こえる
- 3つ目：**右寄り**（右80%）から聞こえる
- 4つ目：**少し右寄り**（右65%）から聞こえる

### 動画が5個以上の場合
- **完全に左**、**完全に右**、**真ん中**の3パターンを繰り返します
- 例：5個なら、左・右・真ん中・左・右の順番

## 開発者向け情報

コードをカスタマイズしたい方や、仕組みを理解したい方向けの情報です。

### ファイル構成

```
├── manifest.json          # 拡張機能の設定
├── background.js          # バックグラウンドで動くプログラム
├── content.js             # ページに注入されるプログラム
├── pack-crx.cmd           # ダブルクリックでCRXを作成
├── scripts/pack-extension.ps1 # CRXの作成・検証処理
├── tests/extension.test.cjs # 依存パッケージ不要の回帰テスト
├── tests/edge-smoke.cjs    # Edge本体を使う任意のスモークテスト
└── README.md              # このファイル
```

実行時は読みやすい `.js` を使用します。既存の `.min.js` は読み込みません。依存パッケージのインストールや開発時のビルドは不要です。

### 技術的な仕組み

この拡張機能は以下の技術を使っています：

- **Chrome Extension Manifest V3**: 最新の拡張機能形式
- **Web Audio API**: ブラウザ標準の音声処理機能
- **StereoPanner**: 左右の音声バランスを調整する機能

### 動作の流れ

1. Holodexへのトップフレームの自動注入、URL遷移、または手動クリックで更新を開始
2. `background.js`が全フレームに`content.js`を注入し、全動画とiframeの矩形を集計
3. iframe階層の座標と拡大率を合成し、表示位置に応じたパン値を各ドキュメントへ送信
4. 各フレームは既存の音声ノードを再利用してパン値だけを更新
5. 自動モードではMutationObserver・ResizeObserverと読み込み/リサイズイベントで変更を検出。監視はmultiview内のみで、定期ポーリングは行わない

### テスト

Node.js 22以降で、外部パッケージをインストールせずに実行できます。

```powershell
node --test tests/extension.test.cjs
node --check background.js
node --check content.js
```

WindowsにEdgeがある場合は、別のテスト専用プロファイルで実ブラウザーの確認もできます。HTTPSのリクエストはローカルのテストHTMLで置き換えるため、実際のHolodexへは接続しません。通常の自動再生制限のままテスト用音源を再生し、音声処理が動作して表示位置に応じたパン値が適用されることを確認します。

```powershell
node tests/edge-smoke.cjs
```

Canaryなど別の実行ファイルを使う場合は、環境変数 `EDGE_PATH` に `msedge.exe` のパスを設定してください。テスト用プロファイルはGit管理外の `env/` に作成します。実際のHolodex/PWAでは、配信の追加・削除・位置交換と左右の聴こえ方も確認してください。

### カスタマイズ方法

コードを編集したい場合：

1. `background.js`の`getPanValues()`が動画数のパターン、`assignPanning()`が表示位置による判定を担当します
2. 数値を変更すれば、好みの左右バランスにできます
   - `-1` = 完全に左
   - `0` = 真ん中
   - `1` = 完全に右
   - `-0.5` = 少し左、など
3. ファイルを保存したら、`chrome://extensions/`または`edge://extensions/`で拡張機能を更新し、対象のページ/PWAも再読み込み

### この拡張機能が必要とする権限

インストール時に以下の権限を要求します：

- **scripting（スクリプト実行）**: ページに音声処理プログラムを注入するため
- **activeTab（アクティブなタブ）**: 今見ているタブの動画を処理するため
- **すべてのサイト**: iframe内の動画も処理できるようにするため

これらの権限は音声処理にのみ使われます。個人情報の収集などは一切行いません。
