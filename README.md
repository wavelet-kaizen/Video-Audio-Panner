# Video Audio Panner

**Holodexなどの複窓ツール専用** - 複数の動画を同時再生する時に、音声を左右に振り分けて聞き分けやすくするChrome拡張機能です。

## これは何？

Holodexなど、**1ページ内に複数の動画を同時再生できるツール**で使うための拡張機能です。

### 解決する問題

Holodexで4つの配信を同時に見ているとき、全ての音声が中央から聞こえて混ざってしまい、誰が何を喋っているのか分からなくなったことはありませんか？

この拡張機能を使うと：
- **左上の動画 → 左のスピーカーから**
- **右上の動画 → 右のスピーカーから**
- **左下の動画 → 少し左寄りから**
- **右下の動画 → 少し右寄りから**

というように、それぞれの音声を別々の方向から聞こえるようにして、格段に聞き分けやすくします。

### 想定している使い方

- **Holodexで複数のVTuber配信を同時視聴**: 推しの配信を2〜4画面で開いて、それぞれの実況を聞き分ける

### 対応しているツール

1ページ内に複数の`<video>`要素を配置するタイプのツールなら、基本的に使えます：
- ✅ Holodex
- ✅ その他の複窓ツール
- ❌ 普通のYouTube（1動画しかないので意味がない）
- ❌ 通常のニコニコ動画（同上）

### 主な特徴

- ツールバーのボタンをワンクリックで即座に適用
- 動画の数（2個、3個、4個…）に合わせて自動的に最適なパターンを選択
- iframe内の動画も含めて全て処理

## インストール方法

### 方法1：開発者モードで使う（推奨）

この拡張機能はChromeウェブストアには公開されていないので、自分でインストールする必要があります。

1. **拡張機能の管理画面を開く**
   - Chromeのアドレスバーに `chrome://extensions/` と入力してEnterキーを押す
   - または、右上の三点メニュー → 「拡張機能」→ 「拡張機能を管理」をクリック

2. **デベロッパーモードをONにする**
   - 画面右上にある「デベロッパーモード」のスイッチをクリックしてONにする

3. **拡張機能を読み込む**
   - 「パッケージ化されていない拡張機能を読み込む」というボタンが表示されるのでクリック
   - ファイル選択ダイアログが開くので、このプロジェクトのフォルダ（`manifest.json`があるフォルダ）を選択
   - 「フォルダーの選択」をクリック

4. **完了**
   - Chromeツールバーに「Video Audio Panner」のアイコンが表示されれば成功です

### 方法2：パッケージファイル（.crx）から使う

もし `.crx` ファイルが用意されている場合：

1. Chromeのアドレスバーに `chrome://extensions/` と入力
2. `.crx` ファイルを画面にドラッグ&ドロップ
3. 「拡張機能を追加」をクリック

## 使い方

とても簡単です。

1. Holodexなどの複窓ツールで、動画を2個以上開く
2. 拡張機能の **Video Audio Panner** ボタンをクリック
3. 自動的に全ての動画の音声が左右に振り分けられます
4. 「○個のVIDEOの音声を振り分けました」というメッセージが表示されたら完了

イヤホンやヘッドホンを使うと、左右の違いがよりはっきり分かります。

## 音声の振り分けパターン

動画の数によって、自動的に最適な振り分けパターンが選ばれます。

### 動画が1個の場合
- **真ん中**から聞こえる（普通の状態と同じ）

### 動画が2個の場合
- 1つ目：**左寄り**（左80%）から聞こえる
- 2つ目：**右寄り**（右80%）から聞こえる

### 動画が3個の場合
- 1つ目：**左寄り**（左80%）から聞こえる
- 2つ目：**右寄り**（右80%）から聞こえる
- 3つ目：**真ん中**から聞こえる

### 動画が4個の場合
- 1つ目：**完全に左**から聞こえる
- 2つ目：**完全に右**から聞こえる
- 3つ目：**少し左寄り**（左65%）から聞こえる
- 4つ目：**少し右寄り**（右65%）から聞こえる

### 動画が5個以上の場合
- **完全に左**、**完全に右**、**真ん中**の3パターンを繰り返します
- 例：5個なら、左・右・真ん中・左・右の順番

## 開発者向け情報

コードをカスタマイズしたい方や、仕組みを理解したい方向けの情報です。

### ファイル構成

```
├── manifest.json          # 拡張機能の設定
├── background.js          # バックグラウンドで動くプログラム
├── content.js             # ページに注入されるプログラム
└── README.md              # このファイル
```

### 技術的な仕組み

この拡張機能は以下の技術を使っています：

- **Chrome Extension Manifest V3**: 最新の拡張機能形式
- **Web Audio API**: ブラウザ標準の音声処理機能
- **StereoPanner**: 左右の音声バランスを調整する機能

### 動作の流れ

1. ユーザーがツールバーのボタンをクリック
2. `background.js`がカウンターをリセットして、ページ内の全てのフレーム（メインページとiframe）に`content.js`を注入
3. 各フレームの`content.js`が、そのフレーム内の動画数をバックグラウンドに報告
4. バックグラウンドは全体の動画数を集計し、各フレームに「何番目から始めるか」を伝える
5. 各フレームは受け取った番号から順番に、パンニングパターンに従って音声を振り分け
6. 全ての動画に新しいオーディオコンテキストを作成して適用

### カスタマイズ方法

コードを編集したい場合：

1. `content.js`の21〜37行目あたりに振り分けパターンが書かれています
2. 数値を変更すれば、好みの左右バランスにできます
   - `-1` = 完全に左
   - `0` = 真ん中
   - `1` = 完全に右
   - `-0.5` = 少し左、など
3. ファイルを保存したら、`chrome://extensions/`で拡張機能の更新ボタン（🔄）をクリック

### この拡張機能が必要とする権限

インストール時に以下の権限を要求します：

- **scripting（スクリプト実行）**: ページに音声処理プログラムを注入するため
- **activeTab（アクティブなタブ）**: 今見ているタブの動画を処理するため
- **すべてのサイト**: iframe内の動画も処理できるようにするため

これらの権限は音声処理にのみ使われます。個人情報の収集などは一切行いません。
